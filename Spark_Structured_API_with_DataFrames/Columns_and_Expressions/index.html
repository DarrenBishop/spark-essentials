Columns and Expressions

DataFrame Processing

val spark = SparkSession.builder()
    .appName("Columns and Expressions")
    .getOrCreateLocal()
// spark: SparkSession = org.apache.spark.sql.classic.SparkSession@2757671
val carsDF = spark.read
  .option("inferSchema", "true")
  .json("path/to/cars.json")
// carsDF: org.apache.spark.sql.package.DataFrame = [Acceleration: double, Cylinders: bigint ... 7 more fields]

carsDF.five()
// +------------+---------+------------+----------+----------------+--------------------+------+-------------+----------+

Manipulating Columns​

Creating Column objects with df.col()​

Define a column directly from a DataFrame

val firstColumn = carsDF.col("name")
// firstColumn: org.apache.spark.sql.Column = name

select with a Column object​

carsDF
  .select(firstColumn)
  .five()
// +--------------------+
// |                name|
// +--------------------+
// |chevrolet chevell...|
// |   buick skylark 320|
// |  plymouth satellite|
// |       amc rebel sst|
// |         ford torino|
// +--------------------+
// only showing top 5 rows

Various column methods​

import org.apache.spark.sql.functions.{col, column, expr}
import spark.implicits._
carsDF
  .select(
    carsDF.col("Name"),
    col("Acceleration"),
    column("Weight_in_lbs"),
    'Year, // Scala symbol, auto-converted to column
    $"Horsepower", // fancier interpolated string, returns a Column object
    expr("Origin") // EXPRESSION
  )
  .five()
// +--------------------+------------+-------------+----------+----------+------+
// |                Name|Acceleration|Weight_in_lbs|      Year|Horsepower|Origin|
// +--------------------+------------+-------------+----------+----------+------+
// |chevrolet chevell...|        12.0|         3504|1970-01-01|       130|   USA|
// |   buick skylark 320|        11.5|         3693|1970-01-01|       165|   USA|
// |  plymouth satellite|        11.0|         3436|1970-01-01|       150|   USA|
// |       amc rebel sst|        12.0|         3433|1970-01-01|       150|   USA|
// |         ford torino|        10.5|         3449|1970-01-01|       140|   USA|
// +--------------------+------------+-------------+----------+----------+------+
// only showing top 5 rows

Expressions with selectExpr​

val weightInLbsExpression = carsDF.col("Weight_in_lbs")
// weightInLbsExpression: org.apache.spark.sql.Column = Weight_in_lbs
val weightInKgExpression = (weightInLbsExpression / 2.2).name("Weight_in_kgs")
// weightInKgExpression: org.apache.spark.sql.Column = /(Weight_in_lbs, 2.2) AS Weight_in_kgs

val carsWithWeightsDF = carsDF.select(
  col("Name"),
  col("Weight_in_lbs"),
  weightInKgExpression,
  $"Weight_in_lbs" / 2.2 as "Weight_in_kgs_2",
  "Weight_in_kgs_3" := $"Weight_in_lbs" / 2.2,
  "Weight_in_kgs_4" := expr("Weight_in_lbs / 2.2"),
)
// carsWithWeightsDF: org.apache.spark.sql.package.DataFrame = [Name: string, Weight_in_lbs: bigint ... 4 more fields]

carsWithWeightsDF.five()
// +--------------------+-------------+------------------+------------------+------------------+---------------+
// |                Name|Weight_in_lbs|     Weight_in_kgs|   Weight_in_kgs_2|   Weight_in_kgs_3|Weight_in_kgs_4|
// +--------------------+-------------+------------------+------------------+------------------+---------------+
// |chevrolet chevell...|         3504|1592.7272727272725|1592.7272727272725|1592.7272727272725|    1592.727273|
// |   buick skylark 320|         3693|1678.6363636363635|1678.6363636363635|1678.6363636363635|    1678.636364|
// |  plymouth satellite|         3436|1561.8181818181818|1561.8181818181818|1561.8181818181818|    1561.818182|
// |       amc rebel sst|         3433|1560.4545454545453|1560.4545454545453|1560.4545454545453|    1560.454545|
// |         ford torino|         3449|1567.7272727272725|1567.7272727272725|1567.7272727272725|    1567.727273|
// +--------------------+-------------+------------------+------------------+------------------+---------------+
// only showing top 5 rows

Note here that := is extension syntax for String; it is an operator alias for (delegates to) Column.name/as.

Rather than defining a Column object and selecting it, we can use selectExpr to do the above in one step:

val carsWithSelectExprWeightDF =
    carsDF.selectExpr("Name", "Weight_in_lbs", "Weight_in_lbs / 2.2")
// carsWithSelectExprWeightDF: org.apache.spark.sql.package.DataFrame = [Name: string, Weight_in_lbs: bigint ... 1 more field]

carsWithSelectExprWeightDF.five()
// +--------------------+-------------+---------------------+
// |                Name|Weight_in_lbs|(Weight_in_lbs / 2.2)|
// +--------------------+-------------+---------------------+
// |chevrolet chevell...|         3504|          1592.727273|
// |   buick skylark 320|         3693|          1678.636364|
// |  plymouth satellite|         3436|          1561.818182|
// |       amc rebel sst|         3433|          1560.454545|
// |         ford torino|         3449|          1567.727273|
// +--------------------+-------------+---------------------+
// only showing top 5 rows

carsWithColumnRenamedDF
  .selectExpr("`Weight in pounds`")
  .two()

// |            3504|

Filtering​

filter and where are aliases:

Union i.e. adding more rows​

val carsCount = carsDF.count()
// carsCount: Long = 406L

val moreCarsDF = spark.read
  .option("inferSchema", "true")
  .json("path/to/more_cars.json")
// moreCarsDF: org.apache.spark.sql.package.DataFrame = [Acceleration: bigint, Cylinders: bigint ... 7 more fields]

val moreCarsCount = moreCarsDF.count()
// moreCarsCount: Long = 2L

val allCarsDF = carsDF.union(moreCarsDF)
// allCarsDF: org.apache.spark.sql.Dataset[org.apache.spark.sql.Row] = [Acceleration: double, Cylinders: bigint ... 7 more fields]
val allCarsCount = allCarsDF.count()
// allCarsCount: Long = 408L

println(s"$carsCount cars and $moreCarsCount cars =>> $allCarsCount total")
// 406 cars and 2 cars =>> 408 total
